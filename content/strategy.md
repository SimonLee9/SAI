# S.A.I Content Strategy

## 핵심 원칙: Build in Public

제작 과정 자체가 콘텐츠이자 마케팅이다.
완성품을 기다리지 않고, 첫 브레드보드 배선부터 공개한다.

## Phase별 콘텐츠 계획

### Phase 0 — 브랜드 런칭 (지금)

| # | 콘텐츠 | 플랫폼 | 비고 |
|---|--------|--------|------|
| 1 | "S.A.I 프로젝트를 시작합니다" 선언문 | Blog + Threads | 첫 인상 결정 |
| 2 | 브레드보드 + 부품 평사진 | Instagram | 비주얼 후킹 |
| 3 | BOM(부품 리스트) 공개 | Blog | 기술적 신뢰 |

## 콘텐츠 제작 규칙

1. **스마트폰으로 충분하다** — 초기에 카메라 장비 투자 금지. 진정성이 장비보다 중요
2. **주 1회 이상** — 어떤 형태든 최소 주 1회 포스팅 유지
3. **아이스버그 전략** — 코드/알고리즘의 세부 파라미터는 절대 공개하지 않음
4. **영어 자막 필수** — 글로벌 타겟이므로 모든 영상에 영어 자막
5. **CTA 포함** — 모든 콘텐츠 마지막에 "팔로우/구독/블로그 링크" 유도
