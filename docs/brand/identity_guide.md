# S.A.I Brand Identity Guide

## Brand Name

- **Full**: S.A.I — Spatial Acoustic Intelligence
- **Korean**: 사이
- **Pronunciation**: "sai" (rhymes with "sky")

## Tagline

> 공간과 소리, 그 사이를 채우는 지능

## Brand Persona

**"Spatial Tech Artist"** — 공간의 질감을 설계하는 하드웨어 아티스트

- 기술을 도구로 사용하는 현대적 장인
- AMR 엔지니어 정체성은 비공개
- "수식 없는 로보틱스" 개념도 비공개

## Visual Identity

### Color Palette

| Name | Hex | Usage |
|------|-----|-------|
| Ink Black | `#1A1A2E` | Primary text, backgrounds |
| Hanji Warm | `#F5F0E8` | Light backgrounds |
| Celadon | `#7BA88C` | Accent, CTAs |
| Copper Gold | `#B8860B` | Premium highlights |
| Signal Blue | `#4A90D9` | Links, tech elements |

### Typography

- Headings: **Pretendard** (한/영 겸용) or **Inter**
- Body: System sans-serif
- Code: JetBrains Mono

### Design Principles

1. **여백의 미** — 과도한 장식 배제, 공간을 살림
2. **기술의 은닉** — 복잡한 기술은 겉으로 드러나지 않게
3. **한국적 곡선** — 달항아리, 창살 문양 등의 모티프 활용

## Content Pillars

| Pillar | Content Type | Example |
|--------|-------------|---------|
| Maker's Log | 제작 과정 | "3D 프린팅 실패 5번째, 드디어..." |

| Founder's Life | 창업 일상 | "부업으로 하드웨어 만들기의 현실" |

## Identity Protection Rules

- ❌ "AMR", "자율주행", "로봇" 단어 사용 금지
- ❌ 회사 사무실, 로봇 장비 사진 노출 금지
- ❌ "수식 없는 로보틱스" 개념 언급 금지
- ✅ "공간 인지 알고리즘", "지능형 동기화" 등 추상적 표현 사용
- ✅ 개인 작업실(책상, 3D 프린터) 공간만 노출
