# web-dashboard/

S.A.I 시스템 제어용 웹 대시보드 (Phase 3)

## Planned Features

- **Node Discovery** — 네트워크상의 마스터/위성 노드 자동 탐색
- **Spatial Map** — 스피커 위치 2D/3D 시각화
- **Calibration Wizard** — 룸 보정 단계별 안내
- **Real-time Visualizer** — 주파수 분석 실시간 시각화
- **Mode Control** — 음향/조명 프리셋 전환
- **IoT Bridge** — Matter/MQTT 연동 설정

## Tech Stack (Planned)

- React + TypeScript + Vite
- WebSocket (ESP32 ↔ Browser 실시간 통신)
- Tailwind CSS
